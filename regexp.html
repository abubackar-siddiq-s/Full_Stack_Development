| Symbol | Meaning | Example | |
| ----------- | ------------------------------------------ | ------------ | ---- |
| `^` | Start of string | `^abc` | |
| `$` | End of string | `abc$` | |
| `[]` | Character set / allowed characters | `[A-Z]` | |
| `[^ ]` | Negation inside brackets (NOT allowed) | `[^0-9]` | |
| `+` | One or more times | `[0-9]+` | |
| `*` | Zero or more times | `[a-z]*` | |
| `?` | Zero or one time (optional) | `colou?r` | |
| `{n}` | Exactly n times | `[0-9]{10}` | |
| `{min,max}` | Between min and max times | `.{8,30}` | |
| `{min,}` | At least min times | `[A-Z]{2,}` | |
| `.` | Any single character | `a.c` | |
| `\.` | Actual dot (`.`) | `gmail\.com` | |
| `\d` | Any digit (same as `[0-9]`) | `\d+` | |
| `\D` | Any non-digit | `\D` | |
| `\w` | Word character (letter, digit, underscore) | `\w+` | |
| `\W` | Non-word character | `\W` | |
| `\s` | White space (space, tab) | `\s` | |
| `\S` | Non-space character | `\S+` | |
| `\t` | Tab character | `\t` | |
| `\n` | New line | `\n` | |
| `\` | Escape special character | `\@`, `\.` | |
| `\|` | OR operator | `cat | dog` |
| `()` | Grouping | `(abc)+` | |
